# 코코포리아 세터

코코포리아(CCFOLIA)로 TRPG(텍스트 롤플레잉) 세션을 진행할 때 필요한 컷인 제작과 로그 백업 작업을 한 번에 처리하는 오프라인 도구입니다.

`Cocofolia_Setter.html` 파일 하나로 동작하며, 서버나 설치 과정 없이 더블클릭해서 브라우저로 열면 바로 사용할 수 있습니다. 인터넷 연결이 필요한 기능도 없습니다(모든 라이브러리가 파일 안에 내장되어 있습니다).

## 사용법

1. `Cocofolia_Setter.html` 파일을 원하는 브라우저(Chrome, Edge 등)로 엽니다.
2. 상단 탭에서 원하는 기능을 선택합니다.
3. 파일을 끌어다 놓거나 클릭해서 선택하면 처리가 시작됩니다. 이미지를 클립보드에 복사해뒀다면 해당 영역에 마우스를 올린 채 Ctrl+V로 바로 붙여넣을 수도 있습니다.
4. 결과물은 각 탭의 다운로드 버튼으로 저장합니다.

## 기능 (탭 구성)

### 1. 컷인 커터
다이스 컷인용 png/gif/apng을 올리면 1회 재생 길이를 자동으로 감지하고, 정확히 같은 길이의 무음 mp3를 만들어줍니다. 코코포리아에서 컷인 이미지와 사운드를 짝지어 재생 시간을 맞출 때 사용합니다. 업로드한 파일은 감지된 길이만큼 1회 미리 재생되어 확인할 수 있습니다.

### 2. GIF APNG 변환기
GIF ↔ APNG를 양방향으로 변환합니다. GIF를 올리면 APNG(무손실 .png)로, 애니메이션 PNG(APNG)를 올리면 GIF로 변환하며 파일 형식은 자동으로 인식합니다. APNG→GIF 변환 시 투명 배경은 크로마키 방식으로 유지할 수 있습니다.

### 3. PNG 이펙터
정지 이미지에 연출 효과를 입혀 짧은 APNG 애니메이션을 만듭니다. 페이드, 글리치, 흔들림, 색수차, 확대/축소, 스캔라인, 회전 지터, 블러(포커스인/아웃), 색조 틴트, 비네트, 노이즈, 플래시, 웨이브 왜곡 등 다양한 효과를 조합해서 사용할 수 있습니다.

### 4. html용 로그 백업
코코포리아의 "로그 출력" 기능으로 받은 .html 파일(또는 확장 프로그램에서 만든 .json)을 올리면, 영화 대본집처럼 GM 서술과 플레이어 대사를 구분해서 깔끔하게 정리해줍니다. 잡담(사담) 탭은 기본적으로 제외되며, 화자 필터/검색/인쇄/HTML 재추출 기능을 제공합니다.

### 5. 로그북용 로그 백업
실물 인쇄용 A5 국배판 로그북 제작을 위한 탭입니다. 실제 조판은 한/글(HWP) 템플릿과 매크로가 담당하며, 이 탭은 로그 HTML을 분석해 각 문단을 대사/주사위/서술 등으로 자동 분류하고 `@@스타일@@본문` 형태의 마커 텍스트로 변환해줍니다. 함께 제공되는 한/글 템플릿+매크로(zip)를 다운로드할 수 있는 버튼도 있습니다.

### 6. CoC 용어 변환기
문장을 번역하지는 않지만, 일본어 CoC 관련 용어나 이미 (다른 곳에서) 번역된 한국어 표기의 흔한 변형을 국내 커뮤니티 표준 용어로 치환해줍니다. 용어 사전은 직접 추가/수정/삭제할 수 있고 JSON으로 내보내기/불러오기가 가능합니다.

### 7. CoC 6판-7판 수치 변환기
6판 능력치(3~18 스케일)를 7판 스케일(×5)로 자동 변환하고, 시나리오 텍스트에 적힌 "STR 12" 같은 표기를 정규식으로 찾아 일괄 변환합니다. Damage Bonus/Build 표는 판본별로 정확한 수치가 필요해 사용자가 직접 입력하는 편집형 표로 제공됩니다.

### 8. 스탠딩 일괄 재단
여러 스탠딩 이미지를 한 번에 같은 비율로 맞춥니다. 크롭(잘라내기)과 레터박스(여백 추가) 중 선택할 수 있고, 이미지별로 세로 위치를 미세조정할 수 있으며 결과물은 ZIP으로 일괄 다운로드됩니다. 이미지는 여러 번에 나눠 올려도 이어붙고, 잘못 올린 이미지는 "제거" 버튼으로 하나만 뺄 수 있습니다.

### 9. 컨닝 페이퍼 메이커
같은 캐릭터의 표정별 스탠딩 이미지를 올리고, 첫 번째 이미지 위에서 원하는 영역(얼굴 등)을 드래그로 지정하면 나머지 이미지에도 같은 위치가 적용되어 표정 카탈로그(컨닝 페이퍼)를 이미지로 만들어줍니다. 이미지는 여러 번에 나눠 올려도 이어붙으며, 순서는 카드를 드래그하거나 ◀▶ 버튼으로 바꿀 수 있고 개별 삭제도 가능합니다. 좌측에 대표 이미지·이름·캐치프레이즈를 넣을 수 있는 캐릭터 패널을 함께 붙일 수 있으며, 한국어와 일본어(가나·한자)를 섞어 써도 글자별로 알맞은 서체(Pretendard / Noto Sans JP 계열)로 자동 렌더링됩니다.

## 폴더 구성

```
Cocofolia_Setter.html    실제 도구 (이 파일 하나만 있으면 됩니다)
Cocofolia_Log_V4/        5번 탭과 연동되는 한/글 템플릿 + 매크로 원본 (자동 동기화, 아래 참고)
```

### Cocofolia_Log_V4 자동 동기화

`Cocofolia_Log_V4/` 폴더와 `Cocofolia_Setter.html`에 내장된 매크로 base64 블록은
더 이상 이 레포에서 직접 수정하지 않습니다. 원본은
[Cocofolia-Log-V4](https://github.com/G909G09/Cocofolia-Log-V4) 레포에서 관리되며,
그 레포의 `main` 브랜치에 push되면 GitHub Actions가 자동으로 이 레포에 반영합니다.
템플릿/매크로를 수정하려면 이 레포가 아니라 Cocofolia-Log-V4 레포를 수정하세요.
(과거에는 `Cocofolia_Log_V4.zip` 사본도 두었지만, 위 폴더 및 5번 탭의 다운로드 버튼과 중복이라 제거했습니다.)

## 기술 메모

- 순수 프론트엔드(HTML/CSS/JS)로만 구현되어 있으며, 서버나 빌드 과정이 없습니다.
- GIF 디코딩(gifuct-js), GIF 인코딩(gif.js.optimized), APNG 인코딩/디코딩(UPNG.js + pako), MP3 인코딩(lamejs), ZIP 생성(JSZip) 라이브러리를 전부 파일 안에 내장했습니다(모두 MIT/오픈소스 라이선스).
- 실제 세션 플레이 로그처럼 타인의 시나리오 내용이 담긴 파일은 저장소에 커밋하지 않습니다(`.gitignore` 참고).
