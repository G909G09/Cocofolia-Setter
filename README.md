# 코코포리아 세터

코코포리아(CCFOLIA)로 TRPG(텍스트 롤플레잉) 세션을 진행할 때 필요한 컷인 제작과 로그 백업 작업을 한 번에 처리하는 오프라인 도구입니다.

`Cocofolia_Setter.html` 파일 하나로 동작하며, 서버나 설치 과정 없이 더블클릭해서 브라우저로 열면 바로 사용할 수 있습니다. 모든 라이브러리·폰트·템플릿이 파일 안에 내장되어 있어 이 파일 하나만 있으면 되고, 인터넷 연결이 필요한 기능은 건의함(GitHub 이슈 연동) 하나뿐입니다.

## 사용법

1. `Cocofolia_Setter.html` 파일을 원하는 브라우저(Chrome, Edge 등)로 엽니다. 처음 열면 홈 화면이 나오며, 업데이트 로그와 카테고리별 기능 블록(마우스를 올리면 설명과 바로가기 버튼이 뜸)을 볼 수 있습니다.
2. 상단 카테고리에 마우스를 올리면 하위 탭 목록이 나오고, 원하는 탭을 클릭해서 이동합니다. "코코세터" 제목이나 "홈" 버튼을 누르면 언제든 홈 화면으로 돌아갈 수 있습니다.
3. 파일을 끌어다 놓거나 클릭해서 선택하면 처리가 시작됩니다. 이미지를 클립보드에 복사해뒀다면 해당 영역에 마우스를 올린 채 Ctrl+V로 바로 붙여넣을 수도 있습니다.
4. 결과물은 각 탭의 다운로드 버튼으로 저장합니다.

## 기능 (탭 구성)

탭이 많아져서 상단에 카테고리(이미지·애니메이션 / 로그 백업 / CoC 유틸리티 / 캐릭터·스탠딩 / 기타)로 묶여 있습니다. 카테고리에 마우스를 올리면(또는 클릭하면) 그 아래 하위 탭 목록이 바뀝니다.

### 1. 컷인 커터
다이스 컷인용 png/gif/apng을 올리면 1회 재생 길이를 자동으로 감지하고, 정확히 같은 길이의 무음 mp3를 만들어줍니다. 코코포리아에서 컷인 이미지와 사운드를 짝지어 재생 시간을 맞출 때 사용합니다. 업로드한 파일은 감지된 길이만큼 1회 미리 재생되어 확인할 수 있습니다.

### 2. GIF APNG 변환기
GIF ↔ APNG를 양방향으로 변환하고, MP4도 APNG로 변환할 수 있습니다. GIF를 올리면 APNG(무손실 .png)로, 애니메이션 PNG(APNG)를 올리면 GIF로, MP4를 올리면 APNG로 변환하며 파일 형식은 자동으로 인식합니다. APNG→GIF 변환 시, 그리고 MP4→APNG 변환 시 모두 투명 배경을 크로마키 방식으로 만들 수 있습니다(색상/허용 오차 지정 가능). MP4 변환은 구간(시작·길이)과 추출 FPS를 지정할 수 있습니다. 기본적으로 코코포리아 업로드 기준(긴 변 1200px, 1MB 이하)에 맞춰 자동으로 축소/압축되며 — 코코포리아는 1MB를 넘는 이미지를 서버에서 압축하는데 이때 애니메이션 정보가 사라지기 때문입니다 — 필요하면 이 자동 리사이징을 끌 수 있습니다.

### 3. PNG 이펙터
정지 이미지에 연출 효과를 입혀 짧은 APNG 애니메이션을 만듭니다. 페이드(상단 옵션)에 더해, 4개의 효과 슬롯에서 각각 드롭다운으로 효과를 골라 최대 4개까지 동시에 조합할 수 있습니다. 효과를 고르면 견본 이미지로 만든 미리보기가 바로 재생되어 어떤 효과인지 텍스트를 읽지 않고도 알 수 있습니다. 글리치, 흔들림, 색수차, 확대/축소, 스캔라인, 회전 지터, 블러(포커스인/아웃), 색조 틴트, 비네트, 노이즈, 플래시, 웨이브 왜곡, 픽셀레이트(모자이크), 색상 반전 플래시, 색상 순환(레인보우), 포스터라이즈, 임팩트 테두리 등 17종 중에서 고를 수 있습니다.

### 4. html용 로그 백업
코코포리아의 "로그 출력" 기능으로 받은 .html 파일(또는 확장 프로그램에서 만든 .json)을 올리면, 영화 대본집처럼 GM 서술과 플레이어 대사를 구분해서 깔끔하게 정리해줍니다. 잡담(사담) 탭은 기본적으로 제외되며, 화자 필터/검색/인쇄/HTML 재추출 기능을 제공합니다.

### 5. 로그북용 로그 백업
실물 인쇄용 A5 국배판 로그북 제작을 위한 탭입니다. 실제 조판은 한/글(HWP) 템플릿과 매크로가 담당하며, 이 탭은 로그 HTML을 분석해 각 문단을 대사/주사위/서술 등으로 자동 분류하고 `@@스타일@@본문` 형태의 마커 텍스트로 변환해줍니다. 함께 제공되는 한/글 템플릿+매크로(zip)를 다운로드할 수 있는 버튼도 있습니다.

### 6. CoC 용어 변환기
문장을 번역하지는 않지만, 일본어 CoC 관련 용어나 이미 (다른 곳에서) 번역된 한국어 표기의 흔한 변형을 국내 커뮤니티 표준 용어로 치환해줍니다. 용어 사전은 직접 추가/수정/삭제할 수 있고 JSON으로 내보내기/불러오기가 가능하며, 수정 내용은 브라우저에 자동 저장되어 다음에 열어도 유지됩니다.

### 7. CoC 6판-7판 수치 변환기
6판 능력치(3~18 스케일)를 7판 스케일(×5)로 자동 변환하고, 시나리오 텍스트에 적힌 "STR 12" 같은 표기를 정규식으로 찾아 일괄 변환합니다. Damage Bonus/Build 표는 CoC 7판 공식 수치가 기본으로 채워져 있어 바로 조회할 수 있고, 다른 룰북을 쓴다면 편집형 표라 직접 고쳐 쓸 수 있습니다(입력 내용은 브라우저에 자동 저장). 이 표는 8번 탭(CoC 캐릭터 시트 메이커)에서도 그대로 쓰입니다.

### 8. CoC 캐릭터 시트 메이커
CoC 7판 캐릭터 시트 형식을 참고한 탐사자 생성기입니다. 처음 만들어보는 사람도 헤매지 않도록 1(기본 정보)→6(JSON 생성) 순서로 번호를 매겨뒀고, "특성치 무작위 굴리기" 버튼으로 CoC 7판 표준 방식(근력·건강·민첩·외모·정신 = 3D6×5, 크기·지능 = (2D6+6)×5, 교육 = (3D6+3)×5)에 맞춰 특성치를 한 번에 굴릴 수 있습니다. 특정 특성치 하나만 다시 굴리고 싶으면 각 카드의 🎲 버튼으로 확인창 없이 바로 다시 굴릴 수 있고, 상단의 "전체 초기화" 버튼을 누르면 이름·특성치·기능치·생성된 JSON까지 이 탭에 입력한 모든 내용을 지우고 새 캐릭터를 처음부터 만들 수 있습니다(확인 필요). 특성치를 입력하면 1/2·1/5 값, 체력·마력·이성·이동력·행운(🎲 버튼으로 3D6×5 굴리기 가능) 같은 파생 수치가 자동으로 계산되고, Damage Bonus/Build는 CoC 7판 공식 표가 내장돼 있어 별도 준비 없이 바로 계산되며(7번 탭에 직접 표를 입력해둔 경우에만 그 표가 우선 적용되고, 계산된 값을 직접 고쳐써도 유지됩니다), 직업 기능점수는 공식을 몰라도 중요 특성치 하나만 고르면 자동으로 계산됩니다. 직업/관심 기능점수 예산을 기준으로 기능치(약 50종 기본 제공, 자유 추가/수정 가능)에 점수를 분배하면 남은 점수가 실시간으로 표시됩니다. 기능 목록은 "카테고리별로 묶어보기"(전투/탐색/행동/교섭/지식, 직접 추가한 기능은 "기타" 구역)와 "전체 목록(기존 방식)" 중 원하는 방식으로 볼 수 있고, 보기를 바꿔도 입력해둔 분배 점수는 그대로 유지되며 선택한 보기 방식은 다음에 열 때도 기억됩니다. 어느 칸이 직접 입력해야 하는 곳이고 어느 칸이 자동 계산되는 곳인지 색으로 구분해뒀고(범례 참고), 특성치·파생 수치는 같은 카드 형태로 통일해 한눈에 훑어보기 쉽습니다. "JSON 생성" 버튼으로 코코포리아 캐릭터 JSON(`{"kind":"character","data":{...}}`)을 만들 수 있고, "JSON 파일로 다운로드"를 누르면 파일로 받을 수 있으며(14번 결과물 보관함에도 함께 모임), "11번 캐릭터 룸파일로 보내기"를 누르면 그 JSON이 11번 탭 스테이터스 입력란에 바로 채워집니다.

### 9. 스탠딩 일괄 재단
여러 스탠딩 이미지를 한 번에 같은 비율로 맞춥니다. 크롭(잘라내기)과 레터박스(여백 추가) 중 선택할 수 있고, 이미지별로 세로 위치를 미세조정할 수 있으며 결과물은 ZIP으로 일괄 다운로드됩니다. 이미지는 여러 번에 나눠 올려도 이어붙고, 잘못 올린 이미지는 "제거" 버튼으로 하나만 뺄 수 있으며 "전체 지우기"로 한 번에 초기화할 수도 있습니다. 목표 비율·처리 방식·출력 폭 등의 설정은 브라우저에 자동 저장되어 다음에 열어도 유지됩니다.

### 10. 컨닝 페이퍼 메이커
같은 캐릭터의 표정별 스탠딩 이미지를 올리고, 첫 번째 이미지 위에서 원하는 영역(얼굴 등)을 드래그로 지정하면 나머지 이미지에도 같은 위치가 적용되어 표정 카탈로그(컨닝 페이퍼)를 이미지로 만들어줍니다. 이미지는 여러 번에 나눠 올려도 이어붙으며, 순서는 카드를 드래그하거나 ◀▶ 버튼으로 바꿀 수 있고, "파일 이름순 정렬" 버튼으로 파일명 기준(숫자 포함 시 자연스러운 순서) 한 번에 정렬할 수도 있으며, 개별 삭제나 "전체 지우기"도 가능합니다. 좌측에 대표 이미지(스탠딩)를 넣을 수 있는 캐릭터 패널을 함께 붙일 수 있으며, 대표 이미지는 세로로 긴 이미지라도 찌그러지지 않고 원본 비율 그대로 표시됩니다. 캐치프레이즈(부제목)와 캐릭터 이름(제목)은 기본적으로 전체 폭을 가로지르는 하단 타이틀 바에 위아래로 함께 그려집니다 — 부제목이 작게 위에, 이름이 로고처럼 크고 굵게 그 아래에. 이름의 배치는 좌측 정렬/우측 정렬(둘 다 하단 타이틀 바) 또는 세로쓰기(대표 이미지가 있을 때 그 옆에, 없으면 우측 정렬로 대신 표시) 중 고를 수 있고, 서체(프리텐다드/프리젠테이션/페이퍼로지 중 선택 — 셋 다 파일에 내장돼 있어 시스템 설치 여부와 무관하게 항상 정확히 표시됩니다)·굵기·색도 따로 지정할 수 있으며, 옆의 미리보기 칸에서 "생성" 버튼을 누르지 않고도 바로 결과를 확인할 수 있습니다. 패널·그리드·타이틀 바 사이에는 구분선을 두지 않아 깔끔하게 이어져 보이며, 표정 라벨은 썸네일 아래 별도 공간 없이 이미지 우측 하단에 흰 테두리를 둘러 겹쳐 그려서 여백을 최소화합니다. 한국어와 일본어(가나·한자)를 섞어 써도 글자별로 알맞은 서체(Pretendard / Noto Sans JP 계열)로 자동 렌더링됩니다. 화질(해상도) 옵션에서 1x/2x/3x 배율을 골라 인쇄 등 고화질이 필요할 때 더 선명한 이미지로 받을 수 있습니다. 다운로드 파일명에는 캐릭터 이름을 입력해뒀다면 그 이름이 함께 붙어서(예: `설이_expression_cheatsheet.png`) 여러 캐릭터의 컨닝 페이퍼를 만들 때 같은 파일명으로 덮어써지지 않습니다. 열 개수·칸 간격·썸네일 크기·패널 폭·화질 설정도 브라우저에 자동 저장됩니다.

### 11. 캐릭터 룸파일 생성기
코코포리아는 캐릭터 1명만 따로 내보내기/가져오기 하는 기능이 없어서, 캐릭터 1명이 담긴 "룸 데이터" 형식(zip)을 만들어 룸 가져오기로 불러올 수 있게 해주는 탭입니다. 표정별 스탠딩 이미지 여러 장을 올리면 파일명을 기준으로 라벨이 자동 지정되고(이미 `@라벨` 형식이 아니면 자동으로 `@`가 붙습니다), 라벨은 직접 수정할 수 있으며 그중 하나를 메인 아이콘으로 고를 수 있습니다. 코코포리아에서 내보낸 캐릭터 스테이터스 JSON(`{"kind":"character","data":{...}}`)을 붙여넣으면 이름·스탯·능력치·커맨드도 함께 채워집니다. 만들어진 zip은 새 룸(또는 테스트용 룸)에 가져온 뒤 캐릭터를 원래 세션 룸으로 옮겨서 사용합니다.

### 12. 건의함
기능 건의나 버그 제보를 남기면 [GitHub 이슈](https://github.com/G909G09/Cocofolia-Setter/issues)로 기록되고, 접수됨/수정중/반영됨/반영 안 됨 상태를 이 탭에서 바로 확인할 수 있습니다. 목록을 보는 건 누구나 가능하지만, 인터넷 연결이 필요하고 새 건의를 남기려면 GitHub 계정이 있어야 합니다.

### 13. 설정
화면 배색을 라이트/다크/시스템 설정 따르기 중에서 고를 수 있고, 선택한 값은 브라우저에 저장되어 다음에 열어도 유지됩니다. 각 탭에서 기억해둔 입력값과 마지막으로 보던 탭, 배색 설정까지 이 브라우저에 저장된 모든 값을 한 번에 지우는 초기화 버튼도 있습니다(업로드한 이미지 등 작업 중인 내용에는 영향 없음).

### 14. 결과물 보관함
컷인·GIF/APNG 변환·PNG 이펙터·로그 백업·스탠딩 재단·컨닝 페이퍼·캐릭터 룸파일·CoC 캐릭터 시트 JSON 등 각 탭에서 "다운로드" 버튼을 누른 결과물이 이 브라우저에도 자동으로 함께 모입니다(IndexedDB에 최근 100개까지 보관, 넘으면 오래된 것부터 지워짐). 위 탭들에는 "다운로드" 버튼 옆에 "임시저장" 버튼도 있어서, 파일을 실제로 다운로드하지 않고도 결과물 보관함에만 남길 수 있습니다(이것저것 만들어보다가 마음에 드는 버전만 나중에 골라 다운로드하고 싶을 때 유용). 나중에 다시 받고 싶을 때 여기서 다운로드하거나, 필요 없어진 항목만 개별 삭제하거나, 전체 삭제할 수 있습니다. 오프라인용 파일 다운로드나 사전 내보내기처럼 "만든 결과물"이 아닌 유틸리티성 다운로드는 여기 모이지 않습니다. 다른 기기·브라우저에서는 보이지 않고, 13번 탭의 "저장된 값 초기화"와는 별개로 관리됩니다.

### Cocofolia_Log_V4 자동 동기화

`Cocofolia_Log_V4/` 폴더와 `Cocofolia_Setter.html`에 내장된 매크로 base64 블록은
더 이상 이 레포에서 직접 수정하지 않습니다. 원본은
[Cocofolia-Log-V4](https://github.com/G909G09/Cocofolia-Log-V4) 레포에서 관리되며,
그 레포의 `main` 브랜치에 push되면 GitHub Actions가 자동으로 이 레포에 반영합니다.
템플릿/매크로를 수정하려면 이 레포가 아니라 Cocofolia-Log-V4 레포를 수정하세요.
(과거에는 `Cocofolia_Log_V4.zip` 사본도 두었지만, 위 폴더 및 5번 탭의 다운로드 버튼과 중복이라 제거했습니다.)

## 기술 메모

- 순수 프론트엔드(HTML/CSS/JS)로만 구현되어 있으며, 서버나 빌드 과정이 없습니다.
- 디자인은 차분한 회색조 배색에 둥근 모서리·옅은 그림자·알약(pill) 모양 버튼/탭을 쓰는 톤을 따르고, 헤더·카드·버튼·입력칸 같은 공용 CSS 컴포넌트만 손봐서 14개 탭 전체에 일관되게 적용됩니다. 라이트/다크 모드 모두 대응합니다(13번 설정 탭에서 전환).
- GIF 디코딩(gifuct-js), GIF 인코딩(gif.js.optimized), APNG 인코딩/디코딩(UPNG.js + pako), MP3 인코딩(lamejs), ZIP 생성(JSZip) 라이브러리를 전부 파일 안에 내장했습니다(모두 MIT/오픈소스 라이선스).
- 기본 글씨체인 프리텐다드(Pretendard Variable)와 10번 탭에서 고를 수 있는 프리젠테이션(Freesentation)·페이퍼로지(Paperlogy)도 웹폰트로 파일 안에 내장해서, 시스템에 따로 설치돼 있지 않아도 항상 정확하게 렌더링됩니다(모두 SIL OFL 1.1 라이선스, 이 때문에 파일 용량이 커졌습니다). Kopub돋움/Kopub바탕은 라이선스상 웹폰트 임베드에 별도 승인이 필요해 파일에 내장할 수 없어서, 선택지에서 제외했습니다.
- 실제 세션 플레이 로그처럼 타인의 시나리오 내용이 담긴 파일은 저장소에 커밋하지 않습니다(`.gitignore` 참고).
- 여러 장을 한꺼번에 올리는 탭(9/10/11번)은 일부 파일이 손상되었거나 지원하지 않는 형식이어도 나머지 파일은 그대로 반영되고, 실패한 파일명만 안내합니다. 파일 드롭존은 마우스뿐 아니라 키보드(Tab으로 포커스 후 Enter/Space)로도 조작할 수 있고, 탭 전환에는 ARIA 탭 시맨틱이 적용되어 있습니다. 마지막으로 보던 탭은 브라우저에 기억해뒀다가 다음에 열 때 그대로 이어서 보여줍니다.
